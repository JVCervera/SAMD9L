# Germline variation and somatic adaptation in SAMD9L-associated disease

Alessandro Liquori and José Cervera, *Leukemia* Letter, revision v20.

[Download the v20 reproducibility archive](SAMD9L_Reproducibility_v20_GitHub.zip?raw=1)

The archive includes the version-matched supplementary workbook, analysis code,
source figures, and frozen AlphaGenome summaries and structural inputs. Extract it
and follow its README. With the dependencies installed in Python 3.12, run
`python reproduce.py --skip-track-checks`.

The complete archive supplied for journal review additionally contains the full
AlphaGenome track exports and their verification scripts.
